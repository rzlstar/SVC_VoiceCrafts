# Simple Voice Changer

Minecraft **26.3** / [Simple Voice Chat](https://github.com/henkelmax/simple-voice-chat) 向けの **Fabric クライアント Mod** です。

Simple Voice Chat がマイク音声を送信する際に音声エフェクトを適用し、自分の声をリアルタイムで加工できます。

ピッチ・音質・エコー・音量を、ゲーム内の設定画面からスライダーで調整できます。

## 主な機能

| 項目 | 説明 | 設定範囲 |
|---|---|---|
| ピッチ | 声の高さを変更します | -24 ～ +24 半音 |
| 音質 | 音声のこもり具合を調整します | 0 ～ 100% |
| エコー量 | エコーの強さを調整します | 0 ～ 100% |
| エコー遅延 | エコーが返ってくるまでの時間を調整します | 0 ～ 1000 ms |
| エコー繰り返し | エコーのフィードバック量を調整します | 0 ～ 90% |
| 音量 | 送信する音声の音量を調整します | 50 ～ 200% |

- **送信音声の加工：** 自分のマイク音声にエフェクトを適用します。
- **ON / OFF 切り替え：** ボタンからエフェクトの有効・無効を切り替えられます。
- **リアルタイム調整：** スライダーを操作すると、設定が音声に反映されます。
- **設定の保存：** 設定は `config/voicechanger.json` に保存されます。

## 必要環境

| ソフトウェア | バージョン |
|---|---|
| Minecraft | 26.3 |
| Fabric Loader | 0.19.3 以上 |
| Fabric API | 0.162.0+26.3 以上 |
| Simple Voice Chat | 2.6.24+26.3 以上 |
| Java | 25 以上 |
| ModMenu（任意） | 21.0.0 以上 |

※ 各バージョンの対応状況は、実際のビルド設定と動作環境に合わせて確認してください。

この Mod はクライアント専用です。サーバー側に Simple Voice Changer を導入する必要はありません。ただし、通話には Simple Voice Chat 本体と通常の接続設定が必要です。

## インストール

1. Minecraft 26.3 に対応した Fabric 環境を用意します。
2. 必要な Mod をダウンロードします。
3. Minecraft の `mods` フォルダに、以下の JAR ファイルを配置します。

   - `fabric-api-*.jar`
   - `voicechat-fabric-2.6.24+26.3.jar`（Simple Voice Chat 本体）
   - `voicechanger-1.0.0.jar`（Simple Voice Changer）

4. ゲームを起動します。
5. **B キー**を押すと設定画面を開けます。

※ B キーは変更可能です。ModMenu を導入している場合は、ModMenu からも設定画面を開けます。

## 使い方

### 設定画面

設定画面では、以下の項目を調整できます。

| 項目 | 内容 |
|---|---|
| ON / OFF | ボイスチェンジャー全体の有効・無効を切り替えます |
| 声質 | ピッチと音質を調整します |
| エコー | エコー量・遅延時間・繰り返し量を調整します |
| 出力 | 送信音声の音量を調整します |
| リセット | 設定を初期値に戻します |
| 完了 | 設定を保存して画面を閉じます |

各スライダーには現在の設定値が表示されます。また、項目にマウスカーソルを合わせると説明が表示されます。

### 音声の変化

- **ピッチを上げる：** 高い声になります。
- **ピッチを下げる：** 低い声になります。
- **音質を下げる：** こもった、無線機のような音になります。
- **エコー量や遅延時間を上げる：** 音が反響するような効果が強くなります。
- **音量を上げる：** 送信音声が大きくなります。

エフェクトの聞こえ方は、マイクや通話環境、各設定値によって異なります。

## 設定ファイル

設定ファイルは `config/voicechanger.json` に保存されます。

初期設定の例：

```json
{
  "enabled": true,
  "pitchSemitones": 0.0,
  "echoDelayMs": 150,
  "echoFeedback": 35,
  "echoWet": 0,
  "tone": 100,
  "gain": 100
}
```

設定ファイルを直接編集することもできます。設定値の範囲外の値は、読み込み時に補正されます。

## ビルド方法

ビルドには JDK 25 以上が必要です。

### 開発環境で起動

Windows：

```bat
gradlew.bat runClient
```

Linux / macOS：

```bash
./gradlew runClient
```

### 配布用 JAR の作成

Windows：

```bat
gradlew.bat build
```

Linux / macOS：

```bash
./gradlew build
```

ビルドが成功すると、通常は `build/libs/voicechanger-1.0.0.jar` に JAR ファイルが生成されます。

## 実装の概要

### 音声処理

- **VoiceChangerPlugin：** Simple Voice Chat API の `ClientSoundEvent` を利用し、音声にエフェクトを適用します。
- **PitchShifter：** 遅延変調方式を利用したピッチシフト処理です。クロスフェードと Catmull-Rom 補間によって、音声の継ぎ目を抑えます。
- **ToneFilter：** 一次ローパスフィルタを使用し、音質スライダーに応じてカットオフ周波数を調整します。
- **EchoEffect：** フィードバック付きディレイラインによるエコー処理です。
- **VoiceEffects：** ピッチ・音質・エコー・音量の各処理を組み合わせます。
- **VoiceChangerScreen：** スライダーや ON / OFF ボタンを備えた設定画面です。

## 注意事項

- 音声処理はクライアント側で行われます。
- ピッチシフトの設定によっては、音声に揺れ（ワブル）が生じる場合があります。
- 音声処理によって通話の遅延が増加する場合があります。
- 他の音声関連 Mod と併用する場合、処理の競合や適用順序によって動作が変わる可能性があります。
