# Simple Voice Changer (ボイスチェンジャー)

Minecraft **26.3** / [Simple Voice Chat](https://github.com/henkelmax/simple-voice-chat) 用の **Fabric** アドオンです。
Simple Voice Chat がマイク音声をエンコードする直前にエフェクトを挟み、**自分の声**をリアルタイムで加工します。
ピッチ・音質（クリアさ）・エコー・音量をすべて**ゲーム内のスライダー**で調整できます。

## 主な機能

| 項目 | 内容 | 範囲 |
| --- | --- | --- |
| ピッチ | 声の高さ（半音単位、±2オクターブ） | -24 〜 +24 半音 |
| 音質（クリアさ） | こもらせ具合。低くすると電話/ロボットのような音に | 0%（こもる）〜 100%（クリア） |
| エコー量 | エコーのかかり具合 | 0 〜 100% |
| エコー遅延 | エコーの遅れ時間 | 0 〜 1000 ms |
| エコー繰り返し | エコーのフィードバック量 | 0 〜 90% |
| 音量 | 送信音量（Simple Voice Chat 側のマイク増幅と併用可） | 50 〜 200% |

- 効果は**送信側（自分のマイク音声）**にのみかかります。相手に届く声が変わります。
- ON/OFF はボタン1つで切り替え可能。OFF のときは音声を一切加工しません。
- 設定は `config/voicechanger.json` に保存されます。

## 必要環境

| ソフト | バージョン |
| --- | --- |
| Minecraft | 26.3 |
| Fabric Loader | 0.19.3 以上（推奨 0.19.5） |
| Fabric API | 0.162.0+26.3 以上 |
| Simple Voice Chat | 2.6.24+26.3 以上 |
| Java | 25 以上 |
| ModMenu（任意） | 21.0.0 以上（設定画面を ModMenu から開けます） |

サーバー側にこの MOD を入れる必要はありません（クライアント専用 MOD です）。
Simple Voice Chat 本体のサーバー設定は通常どおり必要です。

## インストール

1. Fabric Loader を導入した Minecraft 26.3 のプロファイルを用意します。
2. `mods` フォルダに以下を入れます。
   - `fabric-api-*.jar`
   - `voicechat-fabric-2.6.24+26.3.jar`（Simple Voice Chat 本体）
   - `voicechanger-1.0.0.jar`（この MOD）
3. ゲームを起動し、キーボードの **B**（変更可）を押すと設定画面が開きます。

## 使い方

1. サーバーに接続して Simple Voice Chat に接続します（通常の通話設定は済ませておいてください）。
2. **B** キー、または ModMenu の「Simple Voice Changer」から設定画面を開きます。
3. 画面は次の構成です。

   | 場所 | 内容 |
   | --- | --- |
   | 最上段 | ボイスチェンジャー全体の ON / OFF ボタン |
   | 「声質」 | **ピッチ**（声の高さ）、**音質**（クリアさ） |
   | 「エコー」 | **エコー量**、**エコー遅延**、**エコー反復** |
   | 「出力」 | **音量**（送信音量） |
   | 最下段 | **リセット**（初期値に戻す） / **完了**（保存して閉じる） |

   各スライダーは「左に項目名、右にスライダー」の並びで、スライダーの中に現在値が表示されます。
   スライダーにマウスを重ねると、その項目の説明がツールチップで表示されます。
4. スライダーをドラッグすると即座に反映されます。
   - ピッチを上げる → 高い声（いわゆるチップマンク系）
   - ピッチを下げる → 低い声（モンスター系）
   - 音質を下げる → くぐもった/無線機のような声
   - エコー量とエコー遅延を上げる → 洞窟や広間にいるような響き
5. **完了** を押すと `config/voicechanger.json` に保存されます。

## 設定ファイル

`config/voicechanger.json`

```json
{
  "enabled": true,
  "pitchSemitones": 0.0,
  "echoDelayMs": 150,
  "echoFeedback": 35,
  "echoWet": 0,
  "tone": 100,
  "gain": 100
}
```

手で編集しても構いません（読み込み時に範囲外の値は自動的に補正されます）。

## ビルド方法

JDK 25 以上が必要です。

```bash
# 開発環境で実行（Windows では gradlew.bat）
./gradlew runClient

# 配布用 JAR を作成 (build/libs/voicechanger-1.0.0.jar)
./gradlew build
```

ビルド済み JAR は `build/libs/voicechanger-1.0.0.jar` に出力されます。

## 実装の概要

- `VoiceChangerPlugin` … Simple Voice Chat API の `ClientSoundEvent` を購読し、生の 16bit PCM フレームを受け取って加工後のフレームを書き戻します。
  受信側の音声には一切触れません。
- `com.example.voicechanger.audio`
  - `PitchShifter` … 2タップの遅延変調方式（ディレイライン方式）によるピッチシフト。`sin²/cos²` の相補クロスフェードで継ぎ目を消し、Catmull-Rom 補間で読み出します。声質の変化（チップマンク/モンスター）を狙ったシンプルな時間軸処理です。
  - `ToneFilter` … 一次ローパスフィルタ。カットオフ周波数を 400Hz〜16kHz で対数的にマッピングして「音質」スライダーにしています。
  - `EchoEffect` … フィードバック付きディレイライン。
  - `VoiceEffects` … 上記をつないだエフェクトチェーン本体（ピッチ → 音質 → エコー → 音量）。
- `VoiceChangerScreen` … スライダー付きの設定画面。バニラの `Screen` と `AbstractWidget` のみを使用しています。

## 注意事項

- エフェクトはクライアント側の追加処理なので、他のアドオンと併用する場合は適用順に注意してください。
- ピッチシフトはグレイン方式（約21ms）のため、強い設定ではややトレモロ感（ワブル）が出ます。ボイスチェンジャー向けの味付けとして許容しています。
- 通話の遅延がわずかに増えます（ピッチシフト使用時でおよそ 40〜50ms）。
